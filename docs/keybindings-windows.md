# Tastenkürzel Windows (komorebi + whkd) – wie Hyprland auf dem Laptop

Win = SUPER. Quelle: `.config/whkd/whkdrc` (neu laden: Win+Alt+O).
`install.ps1` schaltet dafür Windows-eigene Kombis ab (Win+1–7, Q, C, F, D, O, W; Andocken per Win+Pfeile) –
`install.ps1 -Uninstall` stellt sie wieder her, `-NoWinKeys` lässt sie unangetastet.

| Aktion | Laptop (Hyprland) | Windows |
|---|---|---|
| Terminal | SUPER+Q | Win+Q |
| Dateien | SUPER+E | Win+E (Windows selbst) |
| Obsidian | SUPER+Strg+O | Win+Strg+O |
| Fenster schließen | SUPER+C | Win+C |
| Vollbild | SUPER+F | Win+F (Monokel) |
| Schwebend/gekachelt | SUPER+V | **Win+Shift+Leertaste** (Win+V bleibt Zwischenablage) |
| Teilung drehen | SUPER+O | Win+O |
| Layout wechseln | SUPER+D | Win+D |
| Fokus | SUPER+Pfeile | Win+Pfeile |
| Fenster verschieben | SUPER+Shift+Pfeile | Win+Shift+Pfeile |
| Größe ändern | SUPER+Strg+Pfeile | Win+Strg+Pfeile |
| Arbeitsfläche 1–7 | SUPER+1–7 | Win+1–7 |
| Fenster auf Arbeitsfläche | SUPER+Shift+1–7 | Win+Shift+1–7 |
| Wallpaper | SUPER+W | Win+W (Einstellungen → Hintergrund; wintheme färbt automatisch) |
| Sperren | SUPER+L | Win+L (Windows selbst) |
| Einstellungen | SUPER+I | Win+I (Windows selbst) |
| Übersicht | SUPER+Tab | Win+Tab (Windows selbst) |
| Drop-down-Terminal | SUPER+` | Win+` (Windows Terminal, Quake-Modus) |
| Zwischenablage-Verlauf | SUPER+Shift+V | Win+V (Windows selbst) |
| Screenshot | Druck | Win+Shift+S (Windows selbst) |
| Benachrichtigungen | SUPER+A | Win+N (Windows selbst) |
| Quick Settings | SUPER+S | Win+A (Windows selbst) |
| Neu anordnen / Pause | – | Win+Shift+R / Win+Shift+P |
| komorebi neu laden | – | Win+Shift+O |
